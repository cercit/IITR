# AI PM Portfolio

Small projects that show how I use AI tools to move from a product idea to a working build.

## Projects

### Memory Game: dark theme
A card-matching game in one HTML file. I wrote a PRD for a dark theme, then had Copilot make the change without touching the game logic.

- [PRD](memory-game/dark-theme-prd.md)
- [Game](memory-game/memory-game.html): open in any browser
- Live repo: https://github.com/cercit/memory_game

### Snakes and Ladders
The board game from childhood, in one HTML file. 2 to 4 players on one screen, optional computer player, 10 snakes and 9 ladders, exact roll to finish, a 6 gives another turn.

- [PRD](snakes-and-ladders/PRD.md)
- [Game](snakes-and-ladders/snakes-and-ladders.html): open in any browser
- Tested: zig-zag square order, snake and ladder jumps, overshoot at 98, extra turn on 6, a full 4-player game to a winner, New Game reset, no sideways scroll at 360px.
