# Context: AI PM Portfolio

## What this is
A working portfolio for my product management practice with AI tools. It holds small, finished projects that show how I take an idea from a problem statement to a working product: write the PRD, build it with an AI coding assistant, test it, and ship it through Git.

## Who it is for
Hiring managers and PM peers who want to see how I work, not just what I say I can do.

## What is in it
| Project | What it shows |
|---|---|
| Memory Game (dark theme) | PRD first, then a change to an existing single-file game, with no change to the game logic |
| Snakes and Ladders | PRD first, then a full game with rules, a computer player and tests |

Each project folder has the PRD, the working code, and a short note on what I learned.

## How a project is built
1. Read the existing code and write down what it does.
2. Write a PRD for the change or feature.
3. Make the change with GitHub Copilot or Claude Code.
4. Play or run it and check nothing broke.
5. Commit with a clear message and push.

## Tools
GitHub, Git, VS Code with GitHub Copilot, Claude Code. Games are plain HTML, CSS and JavaScript in one file, so anyone can open them in a browser.

## Rules I keep
- Repos start private. They go public only after I review them.
- No personal or company data in any file.
- Every claim of "done" comes with something I ran or played.
