# Masai Classes

Roadmap and tracker for the Future-Ready Product Management with Applied AI course (IIT Roorkee × Masai, Jul 2026 – Jan 2027).

- `index.html`: every class on a timeline by exam module, with notes and assignment status
- `class.html#<class>`: a 4–5 page readable note per class, with diagrams
- `assignments.html`, `hands-on.html`, `learning.html`, `exams.html`

Rebuild after notes change: `python -I tools/build.py` (reads `../Classes`).
