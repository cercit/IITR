# AI tools learning track

Started 2 Oct 2026. One short course per gap, then a small project so it actually sticks. Tick the box when both the course and the project are done.

Order matters. Do n8n and evals first: n8n shows up in three columns of the FinStack chart, and evals is my biggest gap.

I have a Coursera subscription, so the Coursera courses come with a certificate at no extra cost. The two DeepLearning.AI courses (evals, A2A) are free to watch; skip their paid Pro plan.

Some tools (Visily, Otter, Buffer, Nano Banana/Veo) have no proper Coursera or LinkedIn Learning course. For those, the tool's own free tutorial is better, and the project is the real learning.

---

## 1. Automation + AI Agents: n8n

- **Course:** [Build AI Agents with n8n](https://www.coursera.org/learn/build-ai-agents-n8n) (Coursera, beginner)
- **Project:** an n8n flow that reads my Gmail every morning, picks out FinStack and IJP mails, and sends me a 3-line summary. Then add an AI Agent node that drafts a reply when something needs one.
- [ ] Course  [ ] Project

## 2. AI Evals

- **Course:** [Evaluating AI Agents](https://www.deeplearning.ai/courses/evaluating-ai-agents) (DeepLearning.AI, free, about 2.5 hours). It covers code-based evals and LLM-as-judge.
- **Project:** 20 synthetic cercit applications. Rule-based eval: does the AI recommendation match what the policy engine decided? Then an LLM-judge eval: is the explanation something Rajeev the credit officer can actually use? Report the pass percentage.
- [ ] Course  [ ] Project

## 3. Theoretical: LLM basics + A2A

- **Course:** [Generative AI for Everyone](https://www.coursera.org/learn/generative-ai-for-everyone) (Coursera, Andrew Ng, about 6 hours, no coding)
- **Then:** [A2A: The Agent2Agent Protocol](https://www.deeplearning.ai/courses/a2a-the-agent2agent-protocol) (DeepLearning.AI, about 1.5 hours)
- **Project:** a one-page explainer, "Where cercit uses an LLM and where it must not". Plus one diagram of the Document AI agent handing off to the policy engine, A2A style.
- [ ] Course  [ ] Project

## 4. Prompt: CoT / ToT

- **Course:** [Google Prompting Essentials](https://www.coursera.org/specializations/prompting-essentials-google) (Coursera, under 10 hours)
- **Project:** take 5 prompts I use often. Rewrite each with chain-of-thought, run both versions, and note which one gave the better answer and why. Add the winners to the prompt library in Portfolio-pvt.
- [ ] Course  [ ] Project

## 5. Productivity: NotebookLM + Gamma

- **Course:** [AI for Research and Insights](https://www.coursera.org/learn/google-ai-for-research-and-insights) (Coursera, Google; covers NotebookLM, Deep Research, Gems)
- **Project:** load the FinStack session material into NotebookLM, get a study guide and an audio overview, then turn the summary into a 6-slide Gamma deck.
- [ ] Course  [ ] Project
